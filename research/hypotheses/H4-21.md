# H4-21 — SPY low-volatility regime

*Pre-registered 2026-11-17 before any test was run.*

**Question.** Does holding SPY only when realized volatility is below its one-year median improve risk-adjusted returns?

**Rationale.** Volatility clusters; high-volatility regimes have historically had worse risk-adjusted equity returns.

**Rules.** `lab.strategies.phase4.LowVolTrend` — Hold equities when realised volatility is below its trailing one-year median.
Fixed parameters: `{"median_n": 252}`. Parameter grid: `{"vol_n": [10, 20, 40]}`.

**Data.** SPY, 1d bars, development split only for the search.
**Costs.** profile `default`. **Sizing/risk.** `{"sizing": "pct_equity", "position_pct": 1.0}`; $5,000 start, no leverage.

**Success criteria.** All gates in configs/protocol.yaml (screen at 2× costs, Deflated Sharpe ≥ 0.95, PBO ≤ 0.2, SPA p ≤ 0.05, walk-forward, parameter plateau, yearly consistency), then one validation look.

# H4-02 — BTC daily trend filter (long/flat)

*Pre-registered 2026-11-17 before any test was run.*

**Question.** Does holding BTC only when it is above its 20–200 day average beat buy-and-hold on a risk-adjusted basis?

**Rationale.** Trend filters avoid the deepest drawdowns of trending assets; crypto has had long bear markets.

**Rules.** `lab.strategies.phase4.TrendFilter` — Price above its n-bar moving average -> long (or short below, if allowed).
Fixed parameters: `{}`. Parameter grid: `{"n": [20, 50, 100, 200]}`.

**Data.** BTCUSDT, 1d bars, development split only for the search.
**Costs.** profile `crypto_spot`. **Sizing/risk.** `{"sizing": "pct_equity", "position_pct": 1.0}`; $5,000 start, no leverage.

**Success criteria.** All gates in configs/protocol.yaml (screen at 2× costs, Deflated Sharpe ≥ 0.95, PBO ≤ 0.2, SPA p ≤ 0.05, walk-forward, parameter plateau, yearly consistency), then one validation look.
